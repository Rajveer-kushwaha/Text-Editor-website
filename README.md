# Text Editor Web Application

A simple, browser-based text editor developed using **JSP, HTML, CSS, and JavaScript**. The application provides a clean interface for writing and editing text directly in a web browser.

## 🚀 Live Demo

**Live Website:** https://text-editor-website-avyt.onrender.com/

## ✨ Features

- Write and edit text in the browser.
- Clean and user-friendly interface.
- Interactive controls using JavaScript.
- Custom styling with CSS.
- JSP-based web application.
- Deployed online using Render and Apache Tomcat.

## 🛠️ Technologies Used

- **Java Server Pages (JSP)** — server-side web technology.
- **HTML5** — page structure.
- **CSS3** — styling and layout.
- **JavaScript** — client-side interactivity.
- **Apache Tomcat 11** — web application server.
- **Docker** — application deployment configuration.
- **Render** — cloud hosting platform.

## ⚙️ Run Locally

1. Install Java and Apache Tomcat.
2. Clone or download this repository.
3. Copy the `TextEditor` folder into Tomcat's `webapps` directory.
4. Start the Tomcat server.
5. Open the application in your browser:

```text
http://localhost:8080/TextEditor/
```

*Note: The local URL assumes the application is deployed under the `TextEditor` context path and Tomcat uses port 8080.*

## 🌐 Deployment

The application is deployed on Render using Docker and Apache Tomcat.
